## 📝 On-Page SEO Best Practices

### Title Tags
```
Format: Primary Keyword | Secondary Keyword | Brand
Max length: 60 characters
Example: "Tibetan Singing Bowls | Handcrafted Nepal | Himalayan Handicraft"
```

### Meta Descriptions
```
Format: Action word + Primary keyword + Benefit + Call to action
Max length: 155 characters
Example: "Buy authentic Tibetan singing bowls handcrafted in Nepal. Premium quality meditation bowls with free worldwide shipping. Shop now!"
```

### URL Structure
```
Good: /shop/tibetan-singing-bowls
Bad: /product?id=123

Good: /blog/meditation-with-singing-bowls
Bad: /page.php?post=45
```

### Heading Structure
```html
<h1>Tibetan Singing Bowls - Handcrafted in Nepal</h1>
<h2>Types of Singing Bowls</h2>
<h3>Hand-Hammered Singing Bowls</h3>
<h3>Antique Singing Bowls</h3>
<h2>Benefits of Singing Bowls</h2>
<h3>Meditation Benefits</h3>
<h3>Healing Properties</h3>
```

## 🔍 Keyword Density Guidelines

Target: 1-2% keyword density
- Main keyword: Appears in title, first paragraph, subheadings, conclusion
- LSI keywords: Related terms naturally throughout content
- Avoid keyword stuffing

Example for "Tibetan Singing Bowls":
```
✅ Good: "Our Tibetan singing bowls are handcrafted by master artisans..."
❌ Bad: "Tibetan singing bowls, buy singing bowls, best Tibetan singing bowls..."
```
